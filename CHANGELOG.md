# Changelog

## [1.3] - 2026-09-01

### Added

- Support for 16x02 and 20x04 HD44780 I2C LCDs.
- Support for up to two independent displays.
- Automatic I2C detection and fixed-address configuration.
- Print, Center, Scroll, Clear and Backlight.
- Independent scrolling state for each LCD row.
- Symbol, Draw char and Custom char support.
- Automatic supported accented characters, ° and Ω.
- Independent 8-slot CGRAM management for each LCD.
- Clock with automatic day-of-week calculation.
- Calendar validation and leap-year support from year 2000.
- Independent Alarm support for each Screen.
- Button-controlled Countdown with Ready, Start, Pause, Resume and restart.
- Configurable Countdown CtrlPin and Pull-up.
- Countdown finished? with persistent and One shot modes.
- 10 educational MicroBlocks example projects.
- Illustrated Educational Examples Guide.
- Hardware demonstration photos and videos.
